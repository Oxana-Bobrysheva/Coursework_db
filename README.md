# Проект : Поиск вакансий с подключением Базы Данных

## В рамках проекта необходимо необходимо выполнить три задачи:
### 1. Получить данные о компаниях и вакансиях с сайта hh.ru,
### 2. Спроектировать таблицы в БД PostgreSQL 
### 3. Загрузить полученные данные в созданные таблицы.

## Описание проекта
* Получаем данные о работодателях и их вакансиях с сайта hh.ru. Для этого используется публичный API hh.ru и библиотека 
requests.
* Выбираем не менее 10 интересных вам компаний, от которых вы будете получать данные о вакансиях по API.
* Проектируем таблицы в БД PostgreSQL для хранения полученных данных о работодателях и их вакансиях. Для работы с БД используем библиотеку 
psycopg2.
* Реализуем код, который заполняет созданные в БД PostgreSQL таблицы данными о работодателях и их вакансиях.
* Создаем класс DBManager для работы с данными в БД.

### Класс DBManager
Он будет подключаться к БД PostgreSQL и иметь следующие методы:

`get_companies_and_vacancies_count()`
 — получает список всех компаний и количество вакансий у каждой компании.
`get_all_vacancies()`
 — получает список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию.
`get_avg_salary()`
 — получает среднюю зарплату по вакансиям.
`get_vacancies_with_higher_salary()`
 — получает список всех вакансий, у которых зарплата выше средней по всем вакансиям.
`get_vacancies_with_keyword()`
 — получает список всех вакансий, в названии которых содержатся переданные в метод слова, например python.

### Класс DBManager использует библиотеку psycopg2 для работы с БД.

## Инструкция по запуску проекта
1. В модуле main.py запустите фуккцию, расположенную внизу страницы
```
   if __name__ == "__main__":
    user_interaction_with_db()
```
2. После запуска программа проверяет наличие базы данных 'employers_vacancy', и если 
такая есть, то удаляет её и создаёт новую.
3. Появляется запрос пользователю 
` Введите ключевое слово для поиска компаний (например, 'яндекс'): `
, где нужно ввести ключевое слово.
4. Появляется следующий запрос пользователю ` Введите количество компаний для поиска (до 50): ` , 
в котором нужно указать количество компаний
5. Выводит на экран 10 компаний.
6. Начинает заполнять базу данных компаниями по заданному слову (для наглядности выводит информацию на экран)


## Настройка подключения к базе данных
В корне проекта создайте файл с именем database.ini.
Добавьте в него параметры подключения к вашей базе данных. Пример для PostgreSQL:
```[postgresql]
host=localhost
database=mydatabase
port=5432
user=myuser
password=mypassword
```
Убедитесь, что файл database.ini не попал в систему контроля версий (добавьте его в .gitignore).
